## Important evidence boundaries

- `configs/paper.yaml` requires a real SUMO CSV. `configs/smoke.yaml` uses synthetic mobility and produces validation output only.
- The simulator models reservation compliance and migration mechanics; it does not emulate packet-level wireless behavior.
- IM and DLAPM are transparent behavior-level adaptations based on the mechanisms in references [3] and [5]. They share the paper's initial-placement and feasibility model so the comparison changes only migration behavior. Do not claim bit-for-bit reproduction of the authors' unavailable simulator implementations; see `BASELINE_SPECIFICATION.md`.
- The graph model uses the latest node embeddings to encode current and candidate hosts; graph and temporal dimensions match Table I.
- A physical link generated by this package is bidirectional and becomes two directed arcs. Thus “43 links” means 43 physical backhaul links and 86 directed arcs. State this convention in the paper.
- Initial, RETAIN, and route-only infrastructure changes are immediate, while
  their RL transition is completed at the next request-specific decision or
  terminal event. This avoids a same-time self-transition and is synchronized
  through the wording in `PAPER_TEXT_UPDATE.md`.
